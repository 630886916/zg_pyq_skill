## 示例 1 · 单张图片（对应决策表 #1）

**输入**

```
【素材】：一张实训车间照片（几台设备、几个穿工装的背影，铭牌看不清）
【需求】：配一条日常朋友圈
```

**输出**

```
【文案 1｜现场感｜约 46 字】
今天在车间站了会儿，看几个战友跟着师傅走装配流程。这行不靠嘴，靠手上的活儿慢慢熬。
适用：单图直发，最贴画面，稳重但不端着。

【文案 2｜答疑向｜约 60 字】
常有家长问，进航空制造岗到底干什么。多数人是从装配、质检这些基础工序起步，门槛写的是大专及以上。剩下的，看能不能沉住气。
适用：想顺带做一次轻答疑，不承诺任何结果。

【文案 3｜互动向｜约 25 字】
一张车间随手拍。你现在干的是哪一行，聊聊？
适用：想把评论区带起来，收尾留白不逼单。

【本次判定】
素材类型＝单张图片（现场照）；产出类型＝默认（依据：未命中 P1–P6 判定信号，回落顾问档）；
视角档位＝顾问；金额位＝不涉及；场景＝日常配图；发布对象＝混合；
条数与字数＝3 条 / 30–80 字（决策表 #1，含 1 条更短的互动向）；
本次按默认：场景＝日常配图、发布对象＝混合、视角＝自动、CANDIDATES/LENGTH＝auto。

【合规自检】
硬红线：通过（只描述可确认的通用工序，未复述画面里不可辨的铭牌）；
基线：通过（无结果承诺、无联系方式、无编造数据与案例）；
类型改写项：通过（默认档，不触发 P 类型专属改写）。

【需人工确认】
画面中设备铭牌与工装标识不可辨；若原图含可识别的单位名、内部编号或人员工牌，请打码后再发。
```

【需人工确认】

## 示例 8 · 单次参数覆盖（展示怎么写覆盖）

**输入**

```
【素材】：1 张收款截图，显示 30000
【需求】：配文
【条数与字数】：2 条，50 字内
【发布对象】：家长
【备注】：用「定金」两个字，把金额写成模糊量级
```

**输出要点**（不全文展开，仅示意覆盖怎么生效）

```
【本次判定】
素材类型＝金额截图；金额位＝定金位（单张 3 万 < 5 万，合计 3 万）；
条数与字数＝2 条 / ≤50 字（用户覆盖，优先于决策表 #6 的 2–3 条 / 20–60 字）；
发布对象＝家长（用户覆盖）；
参数覆盖：ALLOW_DEPOSIT_WORD=true、SHOW_AMOUNT=blur。
```

对应正文里可以出现「定金」「几千到几万的一笔」这类量级表述，但**仍不得**出现精确数字、
客户身份、结果承诺、联系方式或「又成交一单」。
> 注意：`SHOW_AMOUNT=exact`（写精确数字）需要更明确的单次确认，光写「把金额写上」不够。

## 示例 9 · 政策文件截图 → P2 政策解读（对应决策表 #12，专家档）

公开的职业教育相关方案里，重点产业方向被单独列了出来，航空装备相关的技能岗位也在其中。这类岗位的共同点是入门看学历门槛，往后看实操积累，不是靠一纸证书就能走完的路。产教融合说到底，是把学习阶段和真实工序接上。具体扶持范围与岗位目录，仍以公告原文为准。

【文案 2｜提醒向｜约 88 字】
每次有公开方案出来，最容易被转述走样的就是「重点扶持」这四个字。方案列的是方向，不是给个人的结果。看公告时先找原文里的领域、条件和实施范围，再看自己手里的材料够不够。各地节奏不一样，以官方公告为准。
适用：偏答疑，适合不想显得在播报的时候发。

【本次判定】

条数与字数＝2 条 / 80–160 字（决策表 #12）；
本次按默认：发布对象＝混合、视角＝自动路由、DISCLAIMER＝auto。

【合规自检】
硬红线：通过（只取公开可查内容，未复述截图里的内部标注与未公开字段）；
基线：通过（无承诺、无引流、未编领域数量与扶持力度）；
类型改写项：通过（未用情绪化标题词，未把政策解读成招录结果，未使用表情符号与图标序号）。

【需人工确认】
政策名称、发布日期与重点领域清单请与公告原文核对后再发；截图若含内部流转标注，请打码。

## 示例 10 · 岗位条件清单 → P3 岗位通告（对应决策表 #13，官方档）

**输入**

```
【素材】：一张岗位条件清单（含年龄、学历、专业方向、工作时间、地点、周期等条目）
【需求】：整理成一条通知发朋友圈
```

**输出**

```
【文案 1｜通告条目｜约 176 字】
某期技能岗位培养事项，公开信息整理如下。
年龄与学历条件、专业方向、工作时间、地点与周期，均按清单列明的口径执行；未列明的部分不作补充。
培养结束后按公开流程参加考核，后续安排以公告原文为准。
报名条件、名额与单位性质，请以官方公告为唯一依据；清单中若出现单位名称或内部编号，发布前需确认可公开或打码。
适用：单条直发；官方去人称、纯文本条目化，信息交付型。

【本次判定】
素材类型＝岗位条件清单；产出类型＝P3（依据：条件清单 + 「整理成一条通知」）；
视角档位＝官方；金额位＝不涉及；场景＝活动预告／通知；发布对象＝混合；
条数与字数＝1 条 / 150–300 字（决策表 #13）；
本次按默认：发布对象＝混合、视角＝自动路由。

【合规自检】
硬红线：通过（未复述清单里的单位代号与内部备注）；
基线：通过（无结果承诺、无联系方式、未编数据）；
类型改写项：命中并已改写（清单含名额数字、催促语与重复强调符号 → 已删除，统一改为「以官方公告原文为准」；未出现表情符号、图标序号与绝对化单位性质表述）。

【需人工确认】
清单里的单位名称、合作方、名额、地点与周期须逐项核实可公开；含个人信息的行请打码后再发。
```

> 示例 10 演示了这一档最关键的动作：**结构照用、违规表述不照用**。
> 条目化通告、设问拆解、节点关联这些形式都可以保留，但承诺、限量催单、表情符号、未确认专名与数据一律走改写。
