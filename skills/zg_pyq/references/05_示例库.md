# 05 · 示例库（完整输入 → 完整输出，v2.0 招生转化版）

> 全部示例按 `../专家提示词.md` 的规则出稿，可当口味基准。
> **全部为中性自造内容**：人名、地区、企业、名额均为示例设定，不含任何真实素材原文与真实学员信息。
> 输出结构统一为三小节：文案块 / 【本次判定】/【合规自检】。

```

```

```
【文案 1】
```

```
✅ 年龄 18–32 周岁
✅ 大专及以上（条件好的可放宽）
✅ 机械、机电、材料、焊接、数控相关专业优先
✅ 能倒班、能吃苦、无不良记录

⏱ 周期：3–6 个月，理论 + 实操
🎯 方向：数控操作、精密装配

结业考核合格，定向输送至航空、航天领域军工单位，
直签正式劳动合同，五险一金。

名额 20 个，报满即止。这一批不收，只能等下一批。
够条件的，直接来问 👇

#军工就业 #数控 #定向培养

年龄 18–32，大专以上，机械、机电、材料、焊接、数控相关专业。
培训 3–6 个月，西安，结业考核合格直接进合作军工单位，直签合同。

为什么限 32 岁？不是嫌年纪大，
```

## 附 · 口味对照（同一个素材，好 vs 坏）

| | 写法 |
|---|---|
| ❌ 素材复述 | 视频中，几位学员正拎着行李走进宿舍楼，办理入住手续。 |
| ❌ 公文腔 | 本期培训班顺利开班，学员将接受系统的技能培训。 |
| ❌ 只有情绪 | 新征程，新起点！热血青年，未来可期！ |
| ❌ 只有清单 | 年龄 18–32，大专以上，机械机电材料焊接数控专业……（无钩子无紧迫） |
| ✅ 招生转化 | 今天又来了 9 位战友。最小的 19 岁，最大的 34 岁。这批 30 个名额，还剩 6 个。 |
