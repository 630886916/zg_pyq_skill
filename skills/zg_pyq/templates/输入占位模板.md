# 输入占位模板（复制下面整段，删掉用不上的行即可）

## 标准版

```
【素材】：
【素材说明】：
【款项性质】：
【需求】：
【场景】：
【条数与字数】：
【视角】：          <顾问 / 专家 / 官方 / 自动>
【产出类型】：      <P1–P6 / 自动>
【防折叠】：        <自动 / 做 / 不做>
【发布对象】：
【备注】：
```

> 所有行都可留空或整行删掉。**只给一张图，或只写一句需求，也照常出稿。**

## 最小输入 · 三种最常用

```
【素材】：（把图片拖进对话 / 贴路径）
【需求】：配一条日常朋友圈
```

```
【需求】：招录季快到了，想发一条提醒性质的朋友圈
```

```
【素材】：（把收款截图拖进对话）
【需求】：配文
```

## 覆盖写法速查（写在【条数与字数】或【备注】）

| 想做的事 | 写这句 |
|---|---|
| 只要一条 | `只要 1 条` |
| 要两条、别太长 | `2 条，50 字内` |
| 多给几条短的 | `5 条短的` |
| 去掉互动向 | `不要互动向` |
| 给家长看 | `【发布对象】：家长` |
| 更稳 / 更口语 | `稳一点` / `口语一点` |
| 用「定金」二字 | `用定金两个字` |
| 允许写模糊金额 | `金额写成模糊量级` |
| 金额截图按全款写 | `【款项性质】：全款位` |
| 每条都带克制声明 | `每条都带一句以官方公告为准` |
| 不带任何克制声明 | `不要加免责` |
| 要防折叠优化 | `做防折叠`（适合的类型才做） |
| 不要防折叠优化 | `不用防折叠` |
| 保留完整清单、别压缩 | `这条要完整清单，不要压缩` |

> 默认 `ANTI_FOLD=auto`：适合的类型（短文案、单图配文、轻互动、P1 / P5 / 中短的 P2 / P6）出稿即写成
> **首句自足、篇幅受控**的形态；P3 岗位通告、P4 人物纪实等信息交付型**不做**，并写明原因。
> 技能只用内容与排版优化，**不用零宽字符、特殊符号或任何防折叠工具**。

> 精确金额（`SHOW_AMOUNT=exact`）需要单独明确说「把截图里的数字原样写进去」，光写「写上金额」不会触发。

## 输入前自检（可选，30 秒）

- [ ] 图片里有没有铭牌、编号、内部看板、工牌、单位名？→ 有就先打码，或在【素材说明】写「含铭牌，请按敏感处理」
- [ ] 聊天/收款截图里有没有姓名、头像、手机号、账号、订单号？→ 技能会提示打码，但**发布前必须自己打**
- [ ] 有没有要用的企业名 / 基地名 / 项目名？→ 写进【备注】并注明「已确认可公开」，否则技能不会落字
- [ ] 这批图是不是分笔支付的多张？→ 技能会自己算合计判定定金位 / 全款位，不放心就在【款项性质】里显式写

## 常见输入 → 会得到什么

| 输入 | 默认出稿 |
|---|---|
| 单张图片 | 3 条 / 30–80 字，含 1 条更短互动向 |
| 视频或截帧 | 2–3 条 / 40–100 字 |
| 只有一句话 | 3 条 / 30–80 字，三个不同角度 |
| 多图 / 九宫格 | 2 条 / 40–90 字 |
| 聊天截图 | 2 条 / 30–70 字 + 打码提示 |
| 1 张金额截图 <5 万 | 2–3 条 / 20–60 字，定金位，不写数字 |
| 多张金额合计 ≥5 万 | 2 条 / 30–70 字，全款位，不写数字 |
