# 输出模板（固定骨架，四个小节不可省）

> 复制下面的骨架用。`<...>` 是填写位，成品里不保留尖括号。
> 正文必须能直接复制发布：无引号、无标题、无 markdown、无 emoji、无话题标签。

```
【文案 1｜<角度标签>｜约 N 字】
<正文，一段 ≤3 句，结尾留白>
适用：<为什么选它 / 配什么素材 / 什么场景发>

【文案 2｜<角度标签>｜约 N 字】
<正文>
适用：…

【文案 3｜<角度标签>｜约 N 字】
<正文>
适用：…

【本次判定】
素材类型＝<五类之一>；金额位＝<定金位 / 全款位 / 不涉及>；场景＝<…>；发布对象＝<…>；
条数与字数＝<N 条 / X–Y 字>（依据：决策表 #<行号> <行名>）；
本次按默认：<列出补了哪些默认值>；参数覆盖：<列出本次覆盖值，无则写「无」>

【合规自检】
硬红线：<通过 / 命中并已改写（写明改法）>｜基线：<通过 / 已关闭 / 命中并已改写（写明改法）>

【需人工确认】
<看不清的元素、待确认专名、款项性质、需打码的具体项、建议更换的素材>；无则写「无」
```

## 角度标签词表（同批不重复）

`现场感` `答疑向` `留白向` `阶段感` `流程向` `经验向` `提醒向` `互动向` `中性`

## 填写要点

| 位置 | 要求 |
|---|---|
| 约 N 字 | 写实际字数，±10 字内 |
| 正文 | 一段 ≤3 句，长短交错，陈述或开放式问句收尾，不加行动指令 |
| 适用 | 写清「为什么选它 / 配什么素材 / 什么场景发」，不写空话 |
| 素材类型 | 单张图片 / 视频截帧 / 纯文字需求 / 多图或聊天截图 / 金额截图 |
| 金额位 | 涉及金额必写，并给判定依据（如「单张 2 万 <5 万，合计 2 万 → 定金位」） |
| 决策表行 | 必须写明行号与行名，方便复核为什么给这个条数和字数 |
| 本次按默认 | 场景、发布对象、条数字数、参数默认值，补了哪几项写哪几项 |
| 合规自检 | 硬红线写「通过」或「命中并已改写 + 改法」；**不输出违规版本** |
| 需人工确认 | 没内容也要写「无」，不能省小节 |

## 精简版（用户明确说「只要文案」时）

仍保留【本次判定】【合规自检】【需人工确认】，只把候选块压缩为一行一条：

```
【文案 1｜现场感｜约 46 字】
今天在车间站了会儿，看几个战友跟着师傅走装配流程。这行不靠嘴，靠手上的活儿慢慢熬。

【文案 2｜答疑向｜约 60 字】
常有家长问，进航空制造岗到底干什么。多数人是从装配、质检这些基础工序起步，门槛写的是大专及以上。剩下的，看能不能沉住气。

【本次判定】…
【合规自检】…
【需人工确认】…
```

> 「只要文案」**不等于**可以省掉后三个小节——它们是这个技能的质检凭证，团队共用时尤其不能省。
