# 输出模板（固定骨架，三小节）

> 复制下面的骨架用。`<...>` 是填写位，成品里不保留尖括号。
> 正文**必须能整段复制粘贴发布**：可以有分段、emoji、话题标签，但不能有 markdown 符号。

```
【文案 1】
<正文。第一行 12–22 字抓人。>

<第二段，1–2 行。>

<第三段，1–2 行，讲清学什么 / 去哪 / 待遇。>

<末行行动 + 一处紧迫 + emoji>

#话题1 #话题2 #话题3

【文案 2】
<正文>

【文案 3】
<正文>

【本次判定】
素材类型：<视频 / 单图 / 多图 / 聊天截图 / 金额截图 / 政策文件 / 岗位清单 / 纯文字需求>
视角档位：<招生方 / 官方通告>
防折叠：<已优化 / 未优化>

【合规自检】
涉密与隐私红线：检测通过
合规红线：通过
```

## 填写要点

| 位置 | 要求 |
|---|---|
| 【文案 N】标题 | **只写编号**。不写角度、不写字数、不写「适用：…」 |
| 正文第一行 | 12–22 字，自足（被折成一行也看得到重点），可带 1 个 emoji |
| 正文分段 | 每段 1–2 行，段与段空一行 |
| emoji | 每条 2–6 个，放行首做锚点；不写 ❗❗❗ |
| 数字 | 阿拉伯数字；人数、年龄、月数、薪资都写数字 |
| 末行 | 行动 + 一处紧迫 + 一个 emoji；不要「欢迎咨询」 |
| 话题标签 | 末行 2–4 个；`HASHTAG=off` 时整行去掉 |
| 素材类型 | **只写类型名**。不写视频多长、图片清不清楚、能不能用 |
| 视角档位 | 招生方 / 官方通告 |
| 防折叠 | 只写「已优化」或「未优化」；**不写做了哪几项、不写原因** |
| 合规自检 | 通过就写「检测通过」「通过」，**后面不跟解释、不加括号** |
| 例外 | 命中红线并改写时才补一句：`涉密与隐私红线：命中并已改写（画面铭牌未复述）` |
| 提醒 | 真有要提醒的（截图含手机号），接在自检下一行：`注：…请打码。` **不加小节标题** |

## 已删除的字段（不要再出现）

产出类型 · 场景 · 发布对象 · 条数与字数 · 本次按默认 · 发布节奏 ·
防折叠边界 · 防折叠细节 · 【需人工确认】小节 · 「适用：…」行

## 一条完整的样子（中性自造，只示排版）

```
【文案 1】
今天又来了 9 位战友 📍

最小的 19 岁，最大的 34 岁，河北、河南、陕西过来的都有。
行李放下就去看车间了，明天正式上手。

他们选的方向不一样 —— 铆接、铺贴、装配，按自己手感和性子挑。
但想要的东西一样：一门能拿到四十岁的技术。

这批 30 个名额，还剩 6 个。想来的，趁这一批 🔥

#退伍军人就业 #航空军工 #技术工种

【文案 2】
三十岁以后，靠体力吃饭的路会越来越窄 ⚠️

同样干十年，有人从操作工干到班组长，有人从学徒干到技师。
差的不是勤奋，是当初选的方向。

体力活有天花板，技术活没有。
什么时候入场？越早越好。

#职业选择 #技术工种

【文案 3】
名额在走，这一批只剩 6 个 ⏱

铆接、铺贴、装配三个方向，一个方向只收 10 人。
满了顺延到下一批，下一批在明年三月。

想来的，问一句就知道合不合适 👇

#定向培养 #航空军工

【本次判定】
素材类型：视频
视角档位：招生方
防折叠：已优化

【合规自检】
涉密与隐私红线：检测通过
合规红线：通过
```
