# 转化文案类型库（M1–M6）

> 本文件是 `专家提示词.md`「六大转化类型」的展开说明，含判定信号、结构骨架、开头句式、中性自造示例。
> **不含任何真实素材原文、真实学员信息、真实企业名。** 示例仅示结构，不得直接套用内容。

---

## 零、先摆正一件事

使用者发素材来，**不是要你描述素材，是要你用素材招人**。

素材的作用只有三个：
1. **作证**（证明我们真的有班级、有设备、有去向、办成过）；
2. **作由头**（今天有件事发生，值得发一条）；
3. **作对比**（别人已经动了，你还没动）。

所以动笔前必须回答：**这条发出去，谁会心动，他心动之后会做什么。**
答不出来，就还没理解素材，不要开始写。

## 一、M1 现场转化（最常用，报到 / 开班 / 上课 / 实训 / 宿舍）

**判定信号**：有人拎行李、有人登记、有人排队、教室坐满、上手操作设备、穿工装集合、宿舍铺床、食堂打饭。

**要干的事**：把"有人来了"变成"你也该来了"。

**结构**
```
① 点人：今天又来了 N 位 / 最小的 19 岁 / 从河北河南过来的
② 他选了什么：铆接 / 铺贴 / 装配 / 数控 / 无损检测
③ 这一步意味着什么：他们不是来上课的，是来换一条路的
④ 名额 / 行动：这批还剩 X 个，想来的趁这一批
```

**开头句式（挑一种，不要每条都用同一种）**
- 「今天又来了 X 位战友，最小的 19 岁，最大的 33 岁。」
- 「上午刚送走一批家长，下午又来三位自己拎着包来的。」
- 「开班第一天，32 个人，18 个是退伍回来的。」
- 「这个点还在车间练手的，是昨天才报到的。」
- 「他们来的理由不一样，想要的东西一样。」

**示例（中性自造，只示结构）**
```
今天又来了 9 位战友 📍

最小的 19 岁，最大的 34 岁，从河北、河南、陕西过来的都有。
行李放下就去看车间了，明天正式上手。

他们选的方向不一样 —— 铆接、铺贴、装配，按自己的手感和性子挑。
但想要的东西一样：一门能拿到四十岁的技术。

这一批 30 个名额，还剩 6 个。
想来的，趁这一批 🔥

#退伍军人就业 #航空军工 #技术工种
```

## 二、M2 政策借势（政策 / 新闻 / 行业数据 / 紧缺目录）

**判定信号**：政策文件截图、新闻标题、政府方案、紧缺职业目录、行业缺口报道、职业教育相关表述。

**要干的事**：把国家方向翻译成个人机会。**不要在开头复述"近日，某某部门印发……"** —— 那是新闻联播，不是招生。

**结构**
```
① 一句结论：国家点名缺人的，就是这几个方向
② 缺口在哪：具体岗位名 + 缺到什么程度（用公开数据或行业通识）
③ 为什么缺：设备多了、老师傅退了、新人不愿意学
④ 时间窗：现在入场是早的，晚三年就是抢
⑤ 行动
```

**开头句式**
- 「国家点名要人，要的就是这几个工种。」
- 「这个方向，缺口不是几十个，是按万人算的。」
- 「政策里没明说的是：这活儿现在没人干。」
- 「十年内不会失业的手艺，基本都写在这份文件里。」

**示例**
```
国家点名缺人的，就是这几个方向 🎯

航空装备、无损检测、精密装配 —— 缺口按万人算，
不是企业不想招，是招不到会干的人。

老师傅一批批退，年轻人不愿意进车间，
这个缺口只会越来越大。

现在入场，你是补缺口的那批人；
再等三年，你是跟几百人抢一个岗位的那批人。

方向选对，比努力更值钱 💪

#航空军工 #技能人才 #退伍军人就业
```

**注意**：政策文件名、文号、具体数字，只有在用户提供或公开可查时才写；否则写"这份文件""这个方向"。

## 三、M3 名额通告（岗位清单 / 开班计划 / 企业内训通知）

**判定信号**：条件清单（年龄、学历、专业）、名额数字、培训周期、就业地点、企业内训、批次安排。

**要干的事**：把条件摆清，把紧迫摆明。**这一类不压缩**（压了会误导），200–320 字可接受。

**结构**
```
① 头部：这批什么、多少名额、什么时候开班
② 谁能报：年龄 / 学历 / 身体 / 专业方向（用短行，一条一行）
③ 学什么、学多久
④ 去哪、什么身份（直签 / 正式合同 / 国企 / 军工单位）
⑤ 名额与行动
```

**开头句式**
- 「只招 20 个。条件写在下面，够的往下看。」
- 「这一批是给企业定向培养的，不是普通培训班。」
- 「名额 15 个，先说明白条件，不合适也别浪费彼此时间。」

**示例**
```
这一批只招 20 人，企业定向培养 ⚠️

✅ 年龄 18–32 周岁
✅ 大专及以上（条件好的可放宽）
✅ 机械、机电、材料、焊接、数控相关专业优先
✅ 能倒班、能吃苦、无不良记录

📍 培训地：西安
⏱ 周期：3–6 个月，理论 + 实操
🎯 方向：数控操作、精密装配

结业考核合格，定向输送至航空、航天领域军工单位，
直签正式劳动合同，五险一金。

名额 20 个，报满即止，这一批不收只能等下一批。
够条件的，直接来问 👇

#军工就业 #数控 #定向培养
```

## 四、M4 去向背书（企业车间 / 签约 / 入职 / 工牌 / 录用通知 / 合影）

**判定信号**：企业门口、车间内部、签约台、工牌、录用通知书、入职合影、薪资结构表、企业来校要人。

**要干的事**：证明"学完真有地方去"，把"包安置"从口号变成画面。

**结构**
```
① 谁来了 / 谁签了：企业来要人、学员已入职
② 什么岗位、什么待遇、什么身份
③ 我们凭什么送得进去：教的就是企业要的、考核标准就是企业标准
④ 你也能站这儿 + 行动
```

**开头句式**
- 「人还没结业，岗位已经排到明年三月。」
- 「今天签完，他年薪从 6 万变成 12 万。」
- 「企业第三次来要人了，这次要 15 个。」
- 「工牌上写的不是'实习生'，是'技术员'。」

**示例**
```
人还没结业，岗位已经排到明年三月 📌

上周来的那家企业，这次直接要 15 个人，
点名要会铆接和装配的，说上手就能干。

为什么敢要？因为我们练的就是他们的工序，
考核标准就是车间的标准，不是学校的标准。

学完出去，身份是技术员，不是学徒。
这一步，早走一年和晚走一年，差的是三五年工资。

下一批开班在即，位置先到先得 💪

#航空军工 #技术员 #定向就业
```

## 五、M5 认知观点（纯文字需求 / 行业观察 / 扎心提问）

**判定信号**：没有素材，或用户只给一句话（"发一条讲讲为什么选这行"）、对比类话题、答疑类。

**要干的事**：卖赛道、卖判断。这一类的说服力来自"敢下结论"，不是信息量。

**结构**
```
① 一句硬观点（12–20 字，能当标题）
② 两三条论证：工资 / 稳定 / 年龄 / 天花板 / 门槛
③ 一句反转或收束（扎心但不刻薄）
④ 行动
```

**开头句式**
- 「选择大于努力，这话在制造业里最真。」
- 「三十岁以后，靠体力吃饭的路会越来越窄。」
- 「不是工作难找，是手上没活的人难找。」
- 「同样是进厂，有人进的是车间，有人进的是技术科。」
- 「这行最扎心的一点：越老越值钱，前提是你得先入行。」

**示例**
```
选择大于努力，这话在制造业最真 ⚠️

同样干十年：
有人从操作工干到班组长，月薪 8000；
有人从学徒干到技师，年薪 20 万。

差的不是勤奋，是当初选的方向。
体力活有天花板，技术活没有。

三十岁以后，靠身体吃饭的路只会越来越窄，
靠手艺吃饭的路才开始变宽。

行业不缺人，缺的是会干的人。
什么时候入场？越早越好 🔥

#职业选择 #技术工种 #航空军工
```

## 六、M6 节点借势（退伍季 / 开学季 / 节日 / 节后 / 纪念日）

**判定信号**：9 月退伍季、3 月春季退伍、开学、春节后返工、国庆、毕业季、节气、纪念日。

**要干的事**：把时间节点变成决策节点。节点只占一句，不要整篇抒情。

**结构**
```
① 节点一句（不煽情，20 字内）
② 这个节点对"你"意味着什么（退伍 / 毕业 / 失业 / 想换行）
③ 窗口正在关：年龄、批次、招聘季
④ 行动
```

**开头句式**
- 「九月退伍，十月就该定了。」
- 「年后是换行最好的时候，也是最后的时候。」
- 「开学季，别人去上学，你去学手艺。」
- 「这一年剩下的时间，够你学会一门活。」

**示例**
```
九月退伍，十月就该定了 📍

从部队回来这段时间，最怕的不是没工作，
是不知道该干什么，一晃半年就过去了。

年龄这道坎不等人：
23 岁进来是学徒，28 岁进来是师傅，33 岁进来只能看运气。

趁现在还有力气学、还有时间试，
把一门手艺拿在手上，比什么都踏实。

十月这批开班，名额不多 💪

#退伍军人就业 #退伍季 #技术工种
```

## 七、钩子与卖点库（组合使用，避免重复）

### 赛道类
未来十年的黄金赛道 · 未来五年的铁饭碗 · 干到退休不下岗的手艺 · 越老越值钱的技术 ·
国家点名的紧缺方向 · 制造业里最抗周期的岗位 · 蓝领里的技术岗，技术岗里的军工岗 ·
不会被 AI 替代的手上活

### 现实类
不看学历看手艺 · 不看关系看技术 · 退伍回来不用从零开始 · 三十岁转行还来得及 ·
第一年工资就比进厂高 · 五险一金 + 正式合同 · 干的是技术不是力气 ·
学三个月，抵得上在流水线站三年

### 信任类
真设备、真工序、真师傅 · 车间的活没法在教室里学会 · 送出去的人企业还会再来要 ·
不承诺天上掉馅饼，只承诺手上有活 · 可以先来看，看完再决定 ·
我们的考核标准就是车间标准

### 紧迫类
名额在走 · 批次不等人 · 招满即止 · 这一批报名比上一批多了四成 ·
同龄人已经上机了 · 犹豫的成本比学费贵 · 年龄窗口一年比一年窄

### 使用纪律
- 同一条里**赛道类最多一句**，堆三句就成广告单页。
- 同批三条候选，**钩子类型必须不同**（一条赛道、一条现实、一条紧迫）。
- 同一句话不要连续两次出现在不同候选里。

## 八、排版细则

| 项 | 规则 |
|---|---|
| 第一行 | 12–22 字，能独立成立，可带 1 个 emoji |
| 段落 | 每段 1–2 行，段间空一行 |
| 锚点 | 行首用 emoji：📍 ✅ 🔥 👉 ⚠️ 🎯 💪 🛠 ⏱ 📌 🇨🇳 |
| emoji 密度 | 每条 2–6 个；不写 ❗❗❗ 这类三连堆叠 |
| 数字 | 用阿拉伯数字；人数、年龄、月数、薪资都写数字 |
| 分隔 | 需要切板块时用「———」，一条最多一处 |
| 标签 | 末尾 2–4 个，`#退伍军人就业` `#航空军工` `#技术工种` `#定向培养` 之类 |
| 长度 | 日常 80–200；通告 200–320；认知 100–180；上限 350 |
| 禁用 | markdown 符号（`#` 作标题、`*`、`>`、`-` 列表）、书面套话、逐字复述素材 |

**结尾三选一**（不要都用"欢迎咨询"）：
- 直接催：`想来的，趁这一批 🔥`
- 低门槛：`不确定自己合不合适，来问一句就知道 👇`
- 画面感：`明年这时候，你可能已经站在车间里了 💪`

## 九、常见失败模式（写完对照删）

| 失败 | 表现 | 改法 |
|---|---|---|
| 素材复述症 | 「视频中，几位学员正拎着行李办理入住」 | 换成点人开头，把"他们在做"改成"你今天可以" |
| 公文腔 | 「本期培训顺利开班，学员将接受系统培训」 | 加人、加数、加结果 |
| 只有情绪没有信息 | 通篇"热血""新征程""致敬" | 补学什么、去哪、多少钱 |
| 只有信息没有钩子 | 一整段条件清单，开头就没劲 | 头部加一句名额或反差 |
| 三条一个味 | 三条都是"黄金赛道 + 名额不多" | 一条现场、一条算账、一条催单 |
| 过度催单 | 每条都"最后 3 个名额！！" | 一条里只留一处紧迫 |
| 编数字 | 素材没给人数却写"今天来了 12 位" | 改"又来了几位""十来个" |
