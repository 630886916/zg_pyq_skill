# 03 · 素材解析规则（v2.1）

> 展开说明。**规则以 `../专家提示词.md` 为准**。
> 核心原则：**看懂素材是为了找招生由头，不是为了描述它。**
> 看得清的元素才写，看不清的绕开，**不猜、不补、不由文案反向造画面**。
> v2.1：看懂工序 ≠ 要写工序。默认不点具体工序 / 岗位名，判定见第八节闸门。

## 零、解析的唯一目的

每看一个素材，只回答三个问题：

1. 它能证明什么？（有人来报名 / 有真设备 / 有真去向 / 有真师傅）
2. 它能让谁心动？（犹豫的人 / 怕学不会的人 / 怕没去处的人 / 怕年龄大了的人）
3. 我要他看完做什么？（来问 / 来看 / 定名额）

**答不出这三问，说明还没看懂素材，不要开始写。**

---

## 一、图片

| 看什么 | 怎么用 |
|---|---|
| 人数与年龄感 | 「又来了几位」「最小的看着不到二十」「这批年纪都不大」 |
| 在做什么 | 报到登记 / 排宿舍 / 上机操作 / 看图纸 / 集合 —— 对应 M1 现场 |
| 环境 | 教室、车间、宿舍、食堂、办公室 —— 决定写"学"还是写"住"还是写"签" |
| 设备与工序 | 只用来判断"是不是真教真练"，**默认不写进文案**；仅文字类岗位素材才写工序 / 岗位名（见第八节闸门） |
| 文字与标牌 | 看不清就当不存在；**看得清也不复述**单位名、编号、代号（硬红线） |

**写法**：从画面里挑**一个最有说服力的点**放大，其余全舍。不要写"画面里有 A、B、C"。

---

## 二、视频

1. **看首帧、中段、尾帧**，抓最有信息的一刻（有人进门 / 有人上手 / 有人签字）。
2. 以那一帧为支点写，不要把整段流程复述一遍。
3. 有口播就抓口播里的态度与承诺；无口播就纯看画面。
4. **不替视频编台词**，不写没听到、没看到的信息。

---

## 三、政策 / 文件 / 岗位清单

只抓三样：

| 抓什么 | 用在哪儿 |
|---|---|
| **缺什么人** | 决定 M2 的结论句（"国家点名缺的就是这几个方向"） |
| **什么条件** | 决定 M3 的门槛条目（年龄、学历、专业、身体） |
| **什么去向** | 决定价值段（去哪、什么身份、什么待遇） |

**不照抄条文**，一律翻成人话。文件名、文号、具体数据：**用户给了或公开可查才写**，
否则写"这份文件""这个方向""政策里写得很直白"。

---

## 四、聊天截图

- 把截图里的**顾虑**当素材，写成答疑向文案（"家长最担心的三件事"）。
- 姓名、头像、昵称、微信号、手机号、订单号 —— **一律不进文案**。
- 不要写成"客户好评"式背书；转述成通用表述。
- 末尾加一句打码提醒（不加小节标题）。

---

## 五、金额截图（报名进度）

| 情况 | 写法 |
|---|---|
| 单张、金额不大 | "又一位战友把名额定下来了""报名先定金，流程慢慢走" |
| 多张、合计较大 | "这一批已经定了十几个""名额在走" |
| 金额看不清 / 信息不全 | 只写报名进度，不提金额 |

- 默认 `SHOW_AMOUNT=false`：**不写具体数字**（客单价不外泄，也不引导比价）。
- 不写客户身份；不写"又成交一单"（像微商晒单，掉价）。
- 需要写数字时，单次明确说「金额数字照写」。

---

## 六、信息不足怎么办

**照常出稿，但用模糊而真实的表达**，不要编：

| 缺什么 | 写什么 | 不要写 |
|---|---|---|
| 人数 | 几位、十来个、这一批人不少 | 今天来了 12 位 |
| 地区 | 河北、河南过来的都有（用户说过才写） | 编一个地区 |
| 名额 | 还剩几个、这批不多 | 只剩 6 个 |
| 待遇 | 五险一金、正式合同、技术岗 | 月薪 12000 |
| 企业 | 合作军工单位、航空领域企业 | 编一个公司名 |

**原则**：模糊但真实 > 精确但虚构。读者一核实就露馅的话，不要写。

---

## 七、解析后立刻做的判断

```
素材类型 → 类型（M1–M6）→ 条数 / 字数 → 三条候选的角度（现场 / 观点或算账 / 名额）
```

三条候选**不要都是同一个角度**，这是最容易偷懒的地方。

---

## 八、工序 / 岗位点名闸门（v2.1，默认不点名）★

解析完素材立刻做这个判断，**在动笔之前**：

| 判定 | 素材 | 文案里能不能出现「铆接 / 铺贴 / 装配 / 铆装 / 数控 / 无损检测」等具体工序或岗位名 |
|---|---|---|
| ✅ 可点（最多一处，不铺开列） | 用户明确要岗位介绍 / 方向说明；**文字类**素材本身写了岗位：岗位清单、招录条件、紧缺职业目录、开班计划、课程表（M3、部分 M2） | 能。这是"把事说清楚" |
| ❌ 不点 | 宣传海报、节日借势（双十一、国庆、纪念日）、优惠报名活动、参观来访、学员报到 / 办入住 / 开班合影、入职签约 / 工牌、聊天截图、金额截图、纯文字需求、只有画面没有文字岗位信息的实训特写 | **不能。全稿一个都不出现** |

⚠️ 关键边界：**「画面里看得出在做什么工序」不算"素材本身包含岗位信息"**。
只有文字类素材白纸黑字写了岗位 / 工种，才算 ✅。照片和视频一律按 ❌ 处理。

**不点名时那一行怎么补**（不要删掉留空，换成读者视角的一句）：
- 之前来问过、还没定下来的，正好赶上这波
- 想换条路的，先来看看再说，看完再决定
- 能不能学会、能不能去、多少岁还能进，问一句给你说清楚
- 名额和时间都在走，别等下一批才想起来
- 学的是能干长久的手艺，出去是技术岗（给身份，不点工序）

**原则：把「我们教什么」换成「你能得到什么 / 你该做什么」。**
这条素材的任务不是介绍岗位，是让人动心、让人来咨询。
参数：`JOB_MENTION = auto`（auto 按上表判定 / on 允许点 / off 一律不点）。
