# 输入占位模板（复制下面整段，删掉用不上的行即可）

## 标准版

```
【素材】：
【需求】：
【类型】：          <M1–M6 / 自动>
【视角】：          <招生方 / 官方通告 / 自动>
【条数】：          <如 3 条 / 只要 1 条 / 自动>
【补充】：
```

> 所有行都可留空或整行删掉。**只给一张图，或只写一句需求，也照常出稿。**

## 【补充】这一行最值钱

技能写得好不好，八成看这一行。给了真实信息，文案就具体、就能打动人。

```
【补充】：这批 28 人，从河北河南过来，剩 6 个名额，学 3–6 个月，
         结业去西安、成都的军工单位，直签合同
```

没给也能写，但只能用「又来了几位」「这一批」「十来个」这类模糊说法。
**不要指望技能替你编人数、名额、企业和待遇 —— 它不会编。**

## 最小输入 · 四种最常用

```
【素材】：（把报到/开班视频拖进对话）
【需求】：发一条
```

```
【素材】：（把车间实训照片拖进对话）
【需求】：配文
```

```
【需求】：想发一条讲为什么建议退伍兵学门手艺的
```

```
【素材】：（把政策文件截图拖进对话）
【需求】：借这个政策发一条
```

## 覆盖写法速查（写在【条数】或【补充】）

| 想做的事 | 写这句 |
|---|---|
| 只要一条 | `只要 1 条` |
| 要两条、别太长 | `2 条，短一点` |
| 多给几条 | `来 5 条` |
| 催得狠一点 | `催得狠一点` / `硬一点` |
| 收着点，别太像广告 | `稳一点` / `别太硬` |
| 主打名额紧迫 | `重点讲名额` |
| 主打待遇和去向 | `重点讲去哪、多少钱` |
| 给家长看 | `写给家长看` |
| 换个类型写 | `【类型】：M5` |
| 用官方通告口吻 | `【视角】：官方通告` |
| 要防折叠优化 | `做防折叠`（适合的类型才做） |
| 不要防折叠 | `不用防折叠` |
| 保留完整清单、别压缩 | `这条要完整清单，不要压缩` |
| 报销金额数字 | `金额数字照写` |
| 加免责 | `结尾加一句以官方公告为准` |

## 输入前自检（30 秒）

- [ ] 画面里有没有铭牌、编号、内部看板、工牌、单位名？→ 有就先打码，或写「含铭牌，请按敏感处理」
- [ ] 聊天/收款截图里有没有姓名、头像、手机号、账号、订单号？→ 技能会提醒，但**发布前必须自己打码**
- [ ] 人数、名额、地区、待遇、企业名 —— 能给就给，写在【补充】里，文案会具体很多
- [ ] 有没有一句话主题？没有也能出稿，但给一句会更准

## 常见输入 → 会得到什么

| 输入 | 默认出稿 |
|---|---|
| 报到 / 入住 / 开班视频 | 3 条 / 100–180 字（现场 + 观点 + 名额） |
| 实训 / 上课 / 车间 | 3 条 / 100–180 字 |
| 企业 / 签约 / 入职照 | 2–3 条 / 100–180 字 |
| 政策 / 新闻截图 | 2–3 条 / 120–200 字 |
| 岗位清单 / 招录条件 | 1–2 条 / 200–320 字（不压缩） |
| 只有一句话 | 3 条 / 100–180 字，三个不同角度 |
| 聊天截图 | 2 条 / 80–140 字 + 打码提示 |
| 金额截图 | 2 条 / 60–120 字，报名进度口吻，默认不写数字 |
