# zg-pyq · 军工航空朋友圈营销文案技能

> **当前版本 v2.1.0**（2026-11-11）｜ **本次更新：新增「工序 / 岗位点名分流闸门」** ——
> 默认不再把铆装、装配、铺贴、无损检测等具体工序 / 岗位名写进文案；仅岗位介绍、岗位清单、
> 政策紧缺目录类可点，节日海报 / 参观 / 报名 / 办入住 / 入职等素材一律不点，
> 改从「吸引人、激发咨询」的角度写。详见 [更新说明.md](更新说明.md)。
> v2.0 为立场重构：从「客观说明素材」改为**招生方用素材做转化**，输出精简为三小节，
> 放开承诺 / 限量 / emoji / 话题标签。
> 完整版本记录见 [更新说明.md](更新说明.md)；已经装过旧版的，看下方「升级到最新版（一句话）」。

> **English** — A portable skill for writing WeChat *Moments* copy **as an admissions/marketing voice** for vocational aviation-training programs. Given an image, video, policy screenshot, job spec, or a one-line brief, it produces 1–3 publish-ready captions built to build trust, trigger sign-ups and create urgency — not to describe the material. Six conversion patterns (on-site, policy, quota notice, placement proof, opinion, seasonal), a hook library, layout rules, and anti-fold optimisation. Hard red line: classified information and personal privacy. **Current version: v2.1.0.**

一个面向 **微信朋友圈（私域招生）** 的文案技能包。
给定素材或一句需求，输出 1–3 条**可直接复制发布**的文案，已排好版（分段、emoji、话题标签）。

技能面向的场景是「军工航空技术培训 / 军工方向就业」的**招生**。
**立场是招生方与培训方，不是旁白**：你发一段学员报到视频，它不会写「视频中几位学员正在办理入住」，
而是写「今天又来了 9 位战友，最小的 19 岁，最大的 34 岁……这批 30 个名额，还剩 6 个」。
其他行业可按 `skills/zg-pyq/专家提示词.md` 里的参数自行调整。

## 它能做什么

| 输入 | 输出 |
|---|---|
| 报到 / 入住 / 开班视频 | 3 条 / 100–180 字（现场 + 观点 + 名额） |
| 实训 / 上课 / 车间 | 3 条 / 100–180 字 |
| 企业 / 签约 / 入职照 | 2–3 条 / 100–180 字 |
| 政策 / 新闻截图 | 2–3 条 / 120–200 字 |
| 岗位清单 / 招录条件 | 1–2 条 / 200–320 字（不压缩） |
| 只有一句话、没有素材 | 3 条 / 100–180 字，三个不同角度 |
| 聊天截图 | 2 条 / 80–140 字 + 打码提示 |
| 金额截图（报名进度） | 2 条 / 60–120 字，默认不写数字 |

条数与字数**按素材自适应**，单次输入可覆盖。

**六类转化类型**（按素材自动路由）：

| 类型 | 命中素材 | 要干的事 |
|---|---|---|
| M1 现场转化 | 报到、开班、实训、宿舍、集合 | 用「又有人来了」制造从众与紧迫 |
| M2 政策借势 | 政策文件、新闻、紧缺目录 | 把国家方向翻成个人机会 |
| M3 名额通告 | 条件清单、开班计划、名额表 | 直接招人，条件 + 紧迫并列 |
| M4 去向背书 | 企业车间、签约、入职、工牌 | 证明学完真有地方去 |
| M5 认知观点 | 纯文字需求、行业观察 | 卖赛道，用观点掰正犹豫 |
| M6 节点借势 | 退伍季、开学季、节后、节日 | 把时间节点变成决策节点 |

判定信号、结构骨架、钩子库与排版细则见 `skills/zg-pyq/references/08_转化文案类型库.md`。

**朋友圈防折叠**：适合的内容（现场、政策、去向、观点、节点、金额截图）**出稿即写成防折叠形态**
——首行自足、篇幅受控、自然分段、三条首行信息点不同；`M3` 岗位通告等长清单**明确不做**，保持完整。
依据官方《微信个人账号使用规范》（2026-10-15 生效）与腾讯客服口径；**官方未公布字数阈值**，故不写死。
只做内容与排版优化，**禁用零宽字符、特殊符号、防折叠码与第三方工具，也不承诺「保证不折叠」**。
详见 `skills/zg-pyq/references/07_朋友圈防折叠设计.md`。

**能力边界**：允许承诺（包安置 / 保就业 / 推荐入职）、允许限量催单（只招 30 人 / 剩 6 个）、
允许晒报名与签约、允许 emoji 与话题标签、允许紧迫与对比。
**唯一硬红线是涉密与他人隐私**；另建议不编造可核查的具体事实（企业名、政策文件名、真实人名、数据）。

## 快速开始

### 1. 装好只要一句话

复制这一行，粘进对话框：

```
帮我装这个技能：https://github.com/630886916/zg_pyq_skill
```

装完刷新一下，直接说：

```
zg-pyq 给这张图配文
```

不用开终端、不用装 Node、不用记路径。它会自己下载、放进技能目录、核对版本，再把结果告诉你。

**其他装法，也都是一行：**

| 你的情况 | 复制这一行 |
|---|---|
| **Windows，想自己装** | `irm https://raw.githubusercontent.com/630886916/zg_pyq_skill/main/install.ps1 \| iex` |
| **Mac / Linux** | `curl -fsSL https://raw.githubusercontent.com/630886916/zg_pyq_skill/main/install.sh \| bash` |
| **Claude Code / Cursor / Codex** | `npx -y skills add 630886916/zg_pyq_skill --skill zg-pyq -g` |
| **完全不想碰命令行** | 下载 `dist/zg-pyq_技能包_20261110.zip` → 解压 → 双击 `安装.bat` |

> Claude Code / Cursor / Codex 那行需要本机装有 Node.js，装完会落到各自的 skills 目录；
> **WorkBuddy 用户用最上面那一句就行**，不用装 Node。
> 终端方式只写技能目录，**不动其他技能**，不需要管理员权限、不需要 Python。
> 如果哪一行跑不通，别纠结 —— 直接用最上面那句话让 Agent 装，或双击 `安装.bat`。
> 想自己一步步来、换别的 Agent、或排查失败：见 [AGENT_INSTALL.md](AGENT_INSTALL.md)（写给我这类 Agent 看的，人不用读）。

**装完怎么确认**：问一句「zg-pyq 你装的哪个版本」，或看 `~/.workbuddy/skills/zg-pyq/SKILL.md` 顶部版本行
（当前应为 `v2.1.0`；也可看 `references/08_转化文案类型库.md` 是否存在）。

> **只想用提示词、不装技能**：把仓库根的 `专家提示词.md` 整份复制成 system prompt，独立可用。

## 规则一览

| 维度 | 要点 |
|---|---|
| **立场** | 招生方 / 培训方。第一人称「我 / 我们」，是招生老师在说话，不是小编、不是观察者 |
| **核心铁律** | **素材是钩子，不是主题**。不描述画面，用画面证明"有人真的来了 / 有真设备 / 有真去向" |
| **三条目标** | ① 积累信任 ② 激起报名欲 ③ 制造紧迫感，缺一条不算合格 |
| **四段结构** | 钩子（12–22 字）→ 事实（1–2 行）→ 价值（学什么 / 去哪 / 待遇 / 干到多少岁）→ 行动（含一处紧迫） |
| **硬红线** | 禁**涉密与他人隐私**，不可关闭：不复述型号参数、内部编号、厂区布局、在职人员姓名、内部文件；截图里的姓名/手机号/微信号不进文案 |
| **已放开** | 承诺（包安置 / 保就业 / 推荐入职）、限量催单（只招 30 人 / 剩 6 个）、晒报名与签约、emoji、话题标签、紧迫与对比 |
| **仍然建议** | 不编造可核查的具体事实（企业名、政策文件名与文号、真实人名、政府数据）；用户给了才写，没给写「合作军工单位」 |
| **转化类型** | M1 现场 / M2 政策 / M3 名额通告 / M4 去向背书 / M5 认知观点 / M6 节点借势，按素材自动路由 |
| **排版** | 首行自足、每段 1–2 行留白、emoji 2–6 个行首锚点、数字用阿拉伯数字、末行 2–4 个话题标签、无 markdown 符号、上限 350 字 |
| **防折叠** | `ANTI_FOLD=auto`：适合的内容出稿即首行自足／篇幅受控；`M3` 长通告明确不做并保持完整。**只做内容／排版层**，禁用零宽字符、特殊符号、第三方工具，不承诺「保证不折叠」 |
| **输出** | **三小节**：文案块 + 【本次判定】三行（素材类型 / 视角档位 / 防折叠）+【合规自检】两行结论 |
| **金额截图** | 当「报名进度」由头写（又一位战友把名额定下来了），默认不写具体数字。详见 `references/03_素材解析规则.md` |

### 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `VOICE` | 招生方 | 招生方 / 官方通告（去人称条目化，用于 M3） |
| `OUTPUT_TYPE` | `auto` | M1–M6，按素材自动路由 |
| `TONE` | 热 | 热（有情绪有招呼）/ 稳（克制）/ 硬（强催单） |
| `MARKETING` | `on` | 承诺 / 限量 / 晒单 / emoji / 话题标签总开关 |
| `EMOJI` / `HASHTAG` | `on` | 每条 emoji 2–6 个 / 末行话题标签 2–4 个 |
| `URGENCY` | `on` | on 每条一处 / soft 只暗示 / off 不提 |
| `CANDIDATES` / `LENGTH` | `auto` | 条数 / 字数区间，走决策表 |
| `ANTI_FOLD` | `auto` | auto / on / off；输出只写结果 |
| `SHOW_AMOUNT` | `false` | 金额截图是否写具体数字 |
| `DISCLAIMER` | `none` | auto＝政策类结尾带一句「具体以官方公告为准」 |
| `HARD_REDLINE` | 涉密与他人隐私 | **常量，不可关闭** |

完整参数表与覆盖写法见 `references/04_输出规范与自适应参数.md`。

## 维护规则

`skills/zg-pyq/专家提示词.md` 是**唯一权威源**；`SKILL.md` 负责触发与调度，`references/` 只做展开说明。
改规则的顺序：权威源 → `SKILL.md` 速查表 → `references/` → 在 `05_示例库.md` 补一个完整示例 → 更新 `更新说明.md` 版本号 → 重新打包 `dist/` 里的 zip → 同步 README 的「当前版本」与 `AGENT_INSTALL.md` 的版本校验项。
改了 `install.ps1` / `install.sh` 要**本地实测一次**（可用 `ZG_PYQ_URL` 指向本地 zip、`ZG_PYQ_DIR` 指向临时目录，避免污染真实技能目录）。
仓库根目录的 `专家提示词.md` 是权威源的字节级副本，**不要单独手改**。
新增或调整转化类型时，同步 `08_转化文案类型库.md`、权威源路由表与决策表、`SKILL.md` 速查表三处。
平台折叠规则会变，但 `07_朋友圈防折叠设计.md` 里的**合规边界（禁符号规避 / 禁第三方工具 / 不承诺结果）不得随规则变动放宽**。
`MARKETING / EMOJI / HASHTAG / URGENCY` 可以按业务需要开关，**但涉密与隐私这条硬红线不能放宽**。

技能 ID 为 `zg-pyq`：目录名必须与 `SKILL.md` frontmatter 的 `name: zg-pyq` 一致，改名时两处一起改。

## 适用范围与注意

- 本技能面向「军工航空技术培训 / 军工方向就业」的招生场景，人设、话术尺度与能力边界都是为该场景定的；用于其他行业前请先通读 `专家提示词.md` 并调参。
- 技能**不改图**。截图里的姓名、头像、账号、订单号、单位名、铭牌、看板等，需由发布者自行打码；技能只负责不把这些写进文案。
- 只处理微信朋友圈语境；抖音标题、简介、评论区话术不在范围内。
- 合规自检由模型执行，**发布责任在人**。招生宣传的法律风险主要来自绝对化用语与无法兑现的具体承诺，承诺口径由业务方确认。
